Custom Building - blueprint template
====================================

This file has a .txt extension on purpose: only *.json files in this folder are read, so this
template is shipped as documentation and never parsed.

Copy it next to itself, rename the copy to <your blueprint name>.json and edit it.  The blueprint
id is "<namespace>:<file name>"; for this folder the namespace is the namespace of the datapack,
so "sakura_cottage.json" placed in
    data/<namespace>/custom_building/blueprint/
becomes
    <namespace>:sakura_cottage


Fields
------

structure  (required)
    The structure template to build.  Written as "name" it is resolved against the namespace of
    this file, "namespace:name" is used as is.
    The matching file must exist at:  data/<namespace>/structure/<name>.nbt

preview  (optional)
    Image shown while hovering the blueprint in a tooltip.  It is always stretched into a 4:3 box.
    Leave it out to show no preview at all.

texture  (optional)
    Inventory texture of the item.  Leave it out, leave it empty or write "default" to use the
    built in blueprint texture (custom_building:textures/item/prefab.png).

name  (optional)
    Item name.  A translation key, or plain text.  Legacy § colour codes are supported.
    Defaults to the blueprint id.

tooltip  (optional)
    One string or an array of strings, same rules as "name".


Texture path spellings
----------------------

All of these mean custom_building:textures/item/sakura_blueprint.png:

    "custom_building:textures/item/sakura_blueprint.png"          full resource location
    "assets/custom_building/textures/item/sakura_blueprint.png"   path as it appears in the jar
    "textures/item/sakura_blueprint.png"                          relative to this file's namespace
    "item/sakura_blueprint.png"                                   "textures/" is added for you
    "item/sakura_blueprint"                                       ".png" is added for you


Example
-------

{
    "structure": "sakura_cottage",
    "preview": "assets/mypack/textures/blueprint/sakura_cottage.png",
    "texture": "assets/mypack/textures/item/sakura_blueprint.png",
    "name": "§d🌸樱花小屋蓝图",
    "tooltip": ["§a右键地面来使用"]
}


After editing run /reload.  The blueprint is added to the "Custom Building" creative tab
immediately, no game restart needed.
